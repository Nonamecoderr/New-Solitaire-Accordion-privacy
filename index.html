2. Какие данные обрабатываются

Сами Приложения не собирают и не передают персональные данные пользователя. Прогресс игры, статистика и настройки хранятся только локально на устройстве и удаляются вместе с приложением.

Приложения показывают рекламу через SDK «Яндекс Мобильная Реклама» (Yandex Mobile Ads). Этот SDK может автоматически обрабатывать технические данные устройства, необходимые для показа и учёта рекламы:

  • рекламный идентификатор устройства (AAID) и идентификаторы SDK;
  • IP-адрес и примерный регион по IP;
  • модель устройства, версия ОС, параметры экрана;
  • сведения о показе, нажатии и закрытии рекламы;
  • данные о работе приложения для диагностики SDK.

Точная геолокация в рекламном SDK отключена настройкой приложения. Поведенческий таргетинг и персонифицированная реклама в Приложениях не используются.

Обработку этих данных выполняет Яндекс как самостоятельный оператор в соответствии со своей политикой: https://yandex.ru/legal/confidential/. Условия работы рекламного SDK: https://yandex.ru/legal/mobileads_sdk/.

3. Цели обработки

  • отображение межстраничной рекламы и рекламы за вознаграждение;
  • учёт показов и начисление вознаграждения за просмотр рекламы;
  • диагностика сбоев рекламного SDK.

4. Дети

Приложения имеют возрастной рейтинг 12+ и не предназначены для детей. Мы не собираем персональные данные детей осознанно.

5. Передача данных третьим лицам

Данные передаются только оператору рекламного SDK (Яндекс) в объёме, указанном в разделе 2, и только для показа рекламы. Мы не продаём и не передаём данные другим третьим лицам.

6. Права пользователя

В соответствии с Федеральным законом РФ № 152-ФЗ «О персональных данных» вы вправе запросить сведения об обработке своих данных, их уточнение, блокирование или удаление, а также отозвать согласие на обработку. Для этого направьте запрос на red6kaya@yandex.ru.

Чтобы полностью удалить локальные данные приложения, удалите приложение с устройства или очистите его данные в настройках системы.

7. Изменение политики

Актуальная версия Политики всегда доступна по адресу этой страницы. Существенные изменения отражаются датой обновления в начале документа.
